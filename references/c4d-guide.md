# C4D 导入帧序列指南

## 一、把帧序列作为材质（最常用）

1. 新建材质（Material Manager → Create → Material）。
2. 打开材质，在 Color（颜色）通道点 Texture（纹理）旁的加载按钮。
3. 选择 `color/`、`lineart/` 或 `cutout/` 目录里的 `frame_000001.png`。
4. 选中该纹理节点，在属性面板勾选 **Image Sequence / Animation（图片序列）**，C4D 会自动按帧号载入整个序列。
5. 把材质赋给 Plane（平面）或 Background（背景）对象，即可逐帧播放。

## 二、工程设置必须匹配

- 打开工程设置（Ctrl/Cmd + D），把 **Frame Rate 设为 24 fps**（与抽帧帧率一致，否则播放速度不对）。
- 时间线总长度按 `manifest.txt` 中的总帧数设置（如 480 帧即 20 秒）。

## 三、线稿上色后回流 C4D

1. 在 Photoshop / Procreate / Krita / Clip Studio 中打开 `lineart/` 里的帧（透明底黑线，直接新建图层正片叠底上色）。
2. 上色后**按原文件名、原帧号、PNG 格式**保存（保持 `frame_000001.png` 连续编号）。
3. C4D 中刷新贴图或重新指定序列首帧即可，帧号不要断号、不要重排。
4. 不想逐帧上色时，只处理 `keyframes/` 里的关键帧，其余帧参考 `basecolor/` 自动底色。

## 四、深度图做 2.5D 立体效果

`depth/` 是灰度深度序列（白=近、黑=远），三种用法：

1. **Displacer 变形器**：给平面加 Displacer，Shader 载入深度序列并勾选图片序列，调高度值，平面随深度起伏。
2. **置换材质**：材质 Displacement 通道载入深度序列，细分平面后产生真实几何位移。
3. **视差分层**：结合 mask 把主体与背景放在不同平面，按深度值错开 Z 轴，做镜头推进的伪 3D 视差。

## 五、蒙版与抠图合成

- `mask/`：载入材质 Alpha 通道（灰度控制透明），实现主体/背景分层，分别打光、加三维元素。
- `cutout/`：已带透明通道的主体 PNG，直接贴图即可，无需再抠。

## 六、作为视口参考图

- 选中视口：View（视图）菜单 → Viewport Back Image/Background，加载序列首帧并启用图片序列，用于建模对位。

## 七、常见问题

| 问题 | 原因与处理 |
|---|---|
| 序列播到一半停住 | 帧号断号或被移动；检查目录中文件是否连续 |
| 画面速度变快/变慢 | 工程帧率与抽帧 fps 不一致，统一为 24 fps |
| C4D 不认序列 | 必须选中首帧而非整个文件夹；确认文件名连续编号 |
| 线稿发黑/线条太碎 | 重跑脚本调大 `--canny-low/--canny-high`（如 80/200）或 `--min-component` |
| 深度方向反了 | 加 `--depth-invert` 重新生成 |
| 路径报错 | 文件夹和路径避免特殊符号，建议纯英文路径 |
